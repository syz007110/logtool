## P1 · 功能清单

### ✅ 已实现的主要功能（基础版已完成）

**故障码管理**

- 故障码增删改查、模糊搜索、导出 CSV/TSV
- 多语言管理（导入/导出 XML、单条/批量导入）
- 故障码查询弹窗（输入完整故障码查详情）
- 故障码相关文案的自动翻译（讯飞 API，仅翻译空白字段）

**日志管理**

- 多文件上传（.medbot，≤50个/200MB）、密钥校验
- 日志解密（含默认密钥切换逻辑）
- 日志解析（故障码匹配、释义、前缀生成）
- 日志列表（按设备分组）
- 批量查看、批量删除、批量重新解析、下载
- 日志查看页（筛选、时间筛选、分析等级、上下文分析、可视化图表、日志摘取）
- 日志自动抓取上传（含队列、集群高峰/非高峰模式）

**手术数据**

- 手术数据统计分析（surgeries 表）
- 手术可视化页面（甘特图、Nightingale Chart、器械卡片）
- 手术数据导出（CSV / HTML-PDF 报告）

**数据解析（运行数据）**

- .bin 文件上传、解析、打包下载
- 按设备分组列表、批量操作

**分析工具（新功能）**

- 三端联动分析工具页（手术视频 + 运行数据 + 日志，统一时间轴）
- 视频播放器（时间锚点配置、与日志/数据联动）

**智能搜索功能**
 智能搜索（自然语言 → LLM 意图识别 → 多源检索 → 证据展示）

**移动端适配**
移动端支持日志查看、手术数据可视化、智能搜索

**用户与权限**

- 注册/登录（自建账号+钉钉免密/扫码）、忘记密码（邮箱验证）
- 用户管理、角色管理（树形权限控制）
- 设备管理（增删改查、密钥管理）
- 系统监控（内存/硬盘/进程/队列状态、手动切换高峰模式）
- 系统操作日志（历史记录页）

**其他**

- 全局看板（用户数/故障码数/日志条目数）
- 缺陷反馈
- 故障案例查询（JIRA + MongoDB 混合搜索、添加/编辑案例）
- 知识库（文件上传、ES 检索、分块索引）
- 智能搜索（自然语言 → LLM 意图识别 → 多源检索 → 证据展示）
- 配置管理页（日志分析等级、故障案例状态、模块、知识库文件类型）
