
## 1.1 登入
### 功能
- 登入方式普通用户在全局配置未开启时仅能通过钉钉认证登录，指定超级管理员保留独立的用户名密码应急登录入口，全局配置仅控制普通用户的用户名密码登录，不影响超级管理员入口；限制只能通过钉钉登入是为了限制企业外的用户登入该系统，这样做的目的是用钉钉管理企业用户的方式来限制非企业人员登入；
- 实际实现方式是 钉钉的账户和系统内的账户是两套，钉钉是由钉钉系统定义的账户系统，而logtool内部还是会维护一套账户系统，内核是通过钉钉的账户换取logtool内部账户系统，通过钉钉免密、扫码登入的都会换取logtool内部的一个账户，与钉钉建立一一绑定的关系；
- 普通用户首次钉钉登录时，由数据库自动生成递增的 id；服务端使用 ULID 生成 username，格式为 `dd_ 加随机且不可预测的唯一字符串`，例如 `dd_01K7H9QX4M7J2A8P6R3T`。数据库 `UNIQUE` 约束保证用户名不重复
- 不提供公开注册或自助创建管超级管理员。首个超级管理员由部署初始化创建；后续管理员仅能由超级管理员在系统内授权或通过受控运维流程创建。
- 无注册功能；
- 无忘记密码的功能；
- 已授权钉钉账户指通过钉钉认证后，服务端必须验证用户属于配置的 dingtalk_corp_id 企业
	验证通过后，首次登录自动创建并绑定 Logtool 内部账户；
	已有内部账户时，必须同时满足 is_active=true 才允许登录。
- 保留用户名和密码登入的方式，但通过一个全局配置来开启或关闭这个登入方式；
	前端根据该配置决定是否显示用户名密码登入的方式（控制是否显示）
	后端根据该配置决定是否可以通过用户名或者密码登入（控制是否可以用用户名或密码登入）
	保留独立的管理登入方式（区别于普通登入的入口），仅支持超级管理员角色登入，前端的预留选择入口页面底部小链接的形式（仅超级管理员支持在该入口使用用户名和密码登入，非超级管理员角色不能通过该入口登入）
	用户名密码登入的方式仍旧遵循密码强度要求：长度：≥ 8 位、必须包含：大写字母（A–Z）、小写字母（a–z）、数字（0–9），不允许：与用户名相同、连续相同字符 ≥ 4 个
		连续失败 3 次后，下一次提交开始要求验证码；
		连续失败 5 次，锁定该用户名的本地密码登录 15 分钟；
		独立的登入IP限流，同一 IP：1 分钟内最多提交 20 次登录请求，使用redis计数的方式；
		超级管理员密码锁定不影响其钉钉登录；
		is_active=false 才阻止该账号所有登录方式。
		用户名不能重复；
- 用户登入失败时需要有对应的提示信息	
- 支持语言切换的功能，根据浏览器自动识别语言；
### 数据库
```SQl
CREATE TABLE IF NOT EXISTS users (
  id INT AUTO_INCREMENT PRIMARY KEY,

  username VARCHAR(100) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NULL,
  local_login_enabled BOOLEAN NOT NULL DEFAULT FALSE,

  email VARCHAR(100) NULL,

  dingtalk_unionid VARCHAR(128) NULL UNIQUE,
  dingtalk_corp_id VARCHAR(128) NULL,
  dingtalk_userid VARCHAR(128) NULL,
  dingtalk_nick VARCHAR(100) NULL,
  dingtalk_bound_at TIMESTAMP NULL,

  is_active BOOLEAN NOT NULL DEFAULT TRUE,
  must_change_password BOOLEAN NOT NULL DEFAULT FALSE,

  scope_id INT NOT NULL DEFAULT 0 COMMENT '暂未启用的数据作用域',
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

  UNIQUE KEY uq_users_dingtalk_corp_user
    (dingtalk_corp_id, dingtalk_userid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```
字段解释说明
`id - Logtool 内部用户主键。业务数据、角色、权限都关联它`
`username -  Logtool 内部唯一用户名，钉钉用户登入后自动生成`
`dingtalk_unionid - 钉钉身份绑定标识，已有唯一约束`
`dingtalk_userid - 用户在某一个钉钉企业组织内的员工 ID。它只在对应企业内有意义，需要与 dingtalk_corp_id 一起使用`
`dingtalk_nick - 是钉钉返回的显示名称：免登场景通常是姓名，扫码场景可能是昵称。它只用于展示，不用于身份判断
`dingtalk_corp_id - 钉钉企业组织 ID。建议新增，并对 (dingtalk_corp_id, dingtalk_userid) 建立联合唯一约束`
`is_active - 账户是否为激活状态`
`password_hash - 本地密码，原先的账户管理方式是必填的，如果改为只支持钉钉登入，必须允许为空`
`must_change_password - 根据是否满足密码强度要求，确定是不是需要修改密码，钉钉用户固定为 false 即可`
`local_login_enabled - 默认 false，仅指定的应急超级管理员允许密码登录`
`scope_id - 暂未启用`
