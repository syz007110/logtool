# 3.增加检索层

Elasticsearch作为检索层，主要发挥以下作用：

1. **全文搜索**：支持中文分词、模糊匹配、相关性排序
2. **多字段联合搜索**：同时搜索多个字段，按权重计算相关性
3. **智能排序**：基于TF-IDF和BM25算法自动计算相关性分数
4. **高性能检索**：倒排索引，毫秒级响应

具体实现：

1. 故障码表按文档方式存入ES
    - 每个故障码的每种语言是一个独立文档
    - 文档ID格式：{errorCodeId}:{lang}（例如：123:zh, 123:en）、每一种语音也是一个独立文档现有zh和en
2. 每个字段有不同的类型
    - keyword类型：精确匹配（code、subsystem等）
    - text类型：全文搜索（short_message、user_hint等）
    - boolean类型：布尔过滤（is_axis_error等）
3. 按文档搜索方式进行检索
    - 多字段联合搜索（类似Google搜索）
    - 自动相关性排序（BM25算法）
    - 支持中文分词（IK插件）
    - 字段权重机制

# 6.日志批量查看功能优化

- 时差转换器，由于日志记录的无时区概念，并且目前都使用北京时区生成的时间戳（UTC+8）,但实际日志可能是其他时区产生的，会导致日志和实际时间有时差，查看日志不方便；所以需要在批量日志查看页面增加时区转换功能，通过下拉菜单选择对应时区，日志列中的时间戳列，按照与UTC+8的关系做时间转换，该转换只影响前端显示，并不会影响数据库，
    - 时间筛选器、搜索表达式，需要也做对应映射；但搜索时对数据的检索需要使用原时间，建立映射关系
    - 手术分析是基于该时差转换后的数据进行统计，可以导出，postgreSQL的structdata增加时差字段
- 高级搜索、时区转换、日志分析等级功能放入侧边栏
    - 高级搜索保留：1.常用表达式、2.导入json、3.自然语言
- 增加自然语言的日志搜索功能，流程是用户输入自然语言（可以是被约束的自然语言）形成意图抽象层，通过意识抽象层转换为检索表达式+执行对应操作；
- 生成检索式支持修改；
    - QuerySpec意识抽象树
    ├─ Scope / Context（查询上下文）
    ├─ Filter AST（条件树，最核心）
    ├─ Action AST（统计 / 标色 / 高亮）
    └─ Meta（是否需要澄清、解释文本）
    - Scope / Context（查询上下文）其中scope用于表示日志选择的范围，由于批量日志页面打开就会有范围，因此自动填充；
    - Filter AST（条件树，最核心）：type: 支持 group、condition、preset_ref
        - group，逻辑组合（AND / OR / 括号）类似根组逻辑；组合多个节点，表达and/or的关系
        - condition,叶子节点（所有判断都在这）,表达一个“最小判断单元”不包含子节点
            - 标准格式是：{
            "type": "condition",
            "field": "…",
            "op": "…",
            "value": "…",
            "negate": false
            }
            - 其中field是批量日志查看中列表字段：时间戳、故障码、参数1、2、3、4、释义；
            - op是逻辑字段级运算符包括=，<，>，contains，
            - "negate": true 就等价于逻辑里的 NOT，仅作用当前的condition
        - preset_ref，引用一个系统内置的常用搜索模板
        - children = 子表达式
        - 
    - Action AST（统计 / 标色 / 高亮）:表示需要执行的动作，type 支持highlight，mark，stats
        - 格式是："actions": [
        { "type": "highlight", "terms": ["param1"] },
        { "type": "mark", "color": "yellow" },
        { "type": "stats", "field": "error_code", "value": "0x431D” }
        ]
        - 其中terms是需要高亮的字段，时间戳、故障码、参数1、2、3、4、释义的单元格；
